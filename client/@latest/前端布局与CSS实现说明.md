# 木序定制前端布局与 CSS 实现说明

## 一、总体布局方法

项目采用 Vue 3 单页应用结构，Vue Router 管理页面跳转。除默认动画展示页外，业务页面统一使用 `PublicLayout.vue`，其中包含顶部导航、页面内容出口与页脚。桌面端内容宽度限制为 1200px，使用 `.container` 保持所有页面标题、筛选区、表格和正文左边线一致。

正式首页不采用常见的多卡片仪表盘布局，而是使用“主视觉 → 悬浮方案入口 → 精选空间 → 定制流程”的纵向层次。悬浮方案入口通过负外边距、定位层级和轻阴影跨越两个页面背景，形成前后层次。

## 二、CSS 文件分工

- `src/styles/tokens.css`：颜色、字体、内容宽度、圆角、阴影和导航高度等设计变量。
- `src/styles/base.css`：盒模型重置、字体、图片、链接、页面容器及常用文字状态。
- `src/styles/element.css`：覆盖 Element Plus 主色、控件高度、表格、对话框、表单和分页样式。
- `src/styles/components.css`：页面标题、筛选条、开放式图片网格、详情双栏、表单分区、工作台双栏等共享模式。
- `src/styles/responsive.css`：平板、移动端和减少动态效果模式。

设计值集中在 CSS 自定义属性中。例如 `--c-primary` 控制按钮和链接主色，`--container` 控制页面内容宽度。更换品牌配色或整体密度时，应优先修改设计变量，而非逐页覆盖。

## 三、Flexbox 的使用

Flexbox 用于一维排列和内容对齐：

- 顶部导航、页面标题与操作按钮。
- 搜索筛选条件和表单底部操作。
- 材质色板、按钮组、消息输入框。
- 订单进度节点内部的图标与文字。

这些区域的主要需求是沿单一方向排列、保持间距并允许换行，因此使用 `display:flex` 比 Grid 更直接。

## 四、CSS Grid 的使用

Grid 用于具有明确行列关系的页面结构：

- 首页主视觉左右分栏。
- 精选空间与产品、案例图片网格。
- 产品详情、案例详情和方案详情的主图/信息双栏。
- 客户工作台的主内容/服务侧栏。
- 在线定制表单的双列表单项。

在 `900px` 或 `767px` 以下，双栏和多列网格会逐步减少为单列，内容顺序仍保持符合阅读和操作流程。

## 五、动画展示页

默认路由 `/` 使用一个高于视口的滚动容器和 `position:sticky` 全屏场景。Vue 监听滚动并计算 0–1 的进度值，通过 CSS 自定义属性驱动：

- 背景图 `scale()` 缩放。
- 亮度滤镜变化。
- 标题透明度和位移。

用户点击“进入木序定制”后由 Vue Router 跳转至 `/home`。当系统开启减少动态效果时，`prefers-reduced-motion` 媒体查询会取消滚动插值，直接显示稳定完成态。

## 六、Element Plus 统一规则

项目没有为每个页面重复编写按钮、输入框和表格主题，而是在 `element.css` 中设置 Element Plus CSS 变量。常规控件高度为 36px，圆角为 4px；表头使用暖灰背景，表格行保持紧凑；对话框标题和底部操作具有一致分隔线。

页面局部样式仅负责该页面独有的布局，不重新定义全局按钮和表单视觉。

## 七、静态 request.js

`src/request/request.js` 提供 `get`、`post`、`put` 和 `delete` 方法，返回 Promise 和统一响应结构：

```js
{ code: 200, message: 'success', data: {} }
```

`src/data/index.js` 注册静态接口处理器，`src/api/` 按产品、订单、认证、个人资料和 AI 助手划分领域方法。Vue 页面只调用 `src/api`，不直接导入业务数据。

接入 Django 时，可将 `request.js` 内部的静态分发替换为 Fetch 或 Axios 请求，并保持 API 文件的函数名称、参数和响应结构不变。这样无需重写页面。

## 八、响应式规则

- 1200px 及以上：完整内容宽度、双栏和多列网格。
- 768–1199px：内容宽度弹性变化，详情侧栏和工作台侧栏根据空间下移。
- 767px 及以下：移动导航、单列网格、表单标签上置、按钮合理堆叠。
- 480px 以下：进一步缩小边距与标题，但保留触控尺寸。

数据表格保留横向滚动能力，不通过删除字段换取移动端适配。图片统一使用 `object-fit:cover`，各页面明确设置稳定高度，避免数据加载后页面跳动。

## 九、端口

客户端在 `vite.config.js` 中固定为 `5173` 并开启 `strictPort`。管理端当前未修改，后续建设时使用 `5172`。
