# 视觉一致性记录

## 设计基准

- 正式首页概念：现代欧式、暖白石材、深胡桃木、编辑式图文排版。
- 默认页概念：全屏柜体场景、深色开场、空间展开、文字分层进入。

## 待浏览器核对项

| 核对点 | 设计要求 | 渲染检查 | 处理结果 |
| --- | --- | --- | --- |
| 首页信息密度 | 只保留主视觉、方案入口、三项系列、四步流程 | 桌面首屏及完整 DOM 已检查 | 未发现额外模块 |
| 首页跨区层次 | 方案入口跨接主视觉与系列区 | 入口以负边距悬浮在主视觉底部 | 保持单一功能元素 |
| 默认页聚焦 | 全屏欧式空间，无常规导航和卡片 | 独立欧式厨房资产、品牌标题和单一入口 | 已替换偏现代的临时图库图片 |
| 字体层级 | 展示宋体与 UI 无衬线明确分工 | 首页标题、页面标题、导航和表格已检查 | 符合设计令牌 |
| 色彩 | 暖白、深胡桃、古铜，单一主强调色 | 首页、工作台、表单均使用统一变量 | 无蓝紫色和装饰渐变 |
| 控件密度 | 36px 控件、小圆角、轻边框 | 工作台表格及在线定制表单已检查 | 保持紧凑可读 |
| 移动端 | 无横向溢出，导航与表单正确折叠 | 390×844 检查首页和在线定制，scrollWidth=innerWidth | 无横向溢出 |

## 有意差异

- 概念图中的图片均为视觉方向示例；实现使用一张项目内生成的欧式厨房主资产和多张室内图库素材，不将概念截图裁切后作为页面内容。
- 默认展示页使用 CSS 滚动亮度与缩放替代逐帧视频，在保持叙事效果的同时减少依赖并支持减少动态效果模式。
