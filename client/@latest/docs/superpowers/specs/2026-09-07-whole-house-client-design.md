# 木序定制客户端设计规格

## 1. 项目目标

在现有 Vue 3 + Vite 初始项目中建设一套面向客户的全屋定制静态前端。项目使用 Vue Router 管理页面，Element Plus 提供基础交互组件，客户端开发端口固定为 `5173`。当前所有页面数据由统一静态请求层返回，后续可在不改变页面数据消费方式的前提下接入 Django API。

本阶段仅建设客户端；管理端不创建、不修改，未来预留端口 `5172`。

## 2. 产品定位与角色边界

客户端服务于有全屋柜体定制需求的客户，覆盖产品与案例浏览、提交需求、查看设计方案、跟踪订单和生产进度、使用 AI 定制助手、维护个人资料等流程。

管理员、设计师、生产和库存管理属于未来管理端范围。本客户端只展示客户有权查看的订单、方案与进度，不提供管理操作，不虚构后台数据能力。

## 3. 视觉方向

整体采用“现代欧式住宅编辑部”风格：保留法式护墙、暖白柜体、石材和深胡桃木的空间气质，但不使用繁复宫廷装饰。页面依靠比例、留白、图文错位、色块切换和细线建立层次，而非依靠大量卡片、阴影或渐变。

### 3.1 色彩

- 页面暖白：`#F5F1EA`
- 功能白：`#FFFFFF`
- 深色区域：`#352820`
- 主文字：`#25221E`
- 次文字：`#756D63`
- 主强调/按钮：`#7B4C32`
- 古铜细节：`#A57A4A`
- 边框：`#DDD5C9`
- 成功状态：低饱和苔绿
- 警告与错误：使用克制的棕橙和暗红，仅承担语义作用

禁止蓝紫渐变、玻璃拟态、彩色大面积渐变、重阴影和无意义装饰色。

### 3.2 字体与层级

- 展示标题使用中文宋体气质字体栈，强调欧式编辑感。
- 导航、正文、表单和表格使用清晰的中文无衬线字体栈。
- 导航与辅助文字：13–14px。
- 正文与表单：14–16px。
- 页面标题：24–28px。
- 区块标题：26–32px。
- 首页主标题：44–50px；移动端降至 34–38px。
- 所有控件显式继承项目字体，避免浏览器默认字体漂移。

### 3.3 几何、间距和层次

- 桌面内容宽度上限 1200px，左右页边距 24px。
- 主要间距采用 8px 基准：8、12、16、24、32、48、64。
- 控件高度以 36px 为主，重点按钮可使用 40px。
- 控件圆角 2–6px，图片圆角 0–4px，禁止大面积胶囊和超大圆角。
- 主要依靠细边框、背景切换、图片前后叠放和非对称网格表达层次。
- 阴影仅用于悬浮方案入口、下拉层和对话框，且保持轻微。

## 4. 信息架构与路由

### 4.1 默认展示与公共页面

- `/`：沉浸式动画展示页。
- `/home`：正式首页。
- `/products`：产品中心。
- `/products/:id`：产品详情。
- `/cases`：案例灵感。
- `/cases/:id`：案例详情。
- `/customize`：在线定制需求表单。
- `/customize/confirm`：需求确认页。
- `/login`：登录。
- `/register`：注册。

### 4.2 客户页面

- `/workspace`：我的定制工作台。
- `/orders`：订单列表。
- `/orders/:id`：订单详情与生产进度。
- `/schemes/:id`：设计方案详情。
- `/assistant`：AI 定制助手静态交互页。
- `/profile`：个人中心。
- `/:pathMatch(.*)*`：404 页面。

公共顶部导航统一跳转正式首页和各业务页面。静态阶段允许直接访问客户页面；路由元信息保留未来鉴权扩展位置。

## 5. 默认动画展示页

默认路由使用全屏现代欧式柜体场景，借鉴高端产品网站的滚动叙事原则，但不复制 Apple 品牌、文案或具体页面结构。

动画分为三段：

1. 暗场材质细节：背景近黑，品牌字样和空间轮廓出现。
2. 空间展开：随滚动增加背景亮度与尺度，主标题“空间，自有秩序”分层淡入。
3. 完整空间：欧式柜体全景稳定呈现，出现“进入木序定制”操作并跳转 `/home`。

动画使用 CSS `position: sticky`、`transform`、`opacity`、`clip-path` 和 Vue 计算的滚动进度实现，不添加动画依赖。必须支持 `prefers-reduced-motion: reduce`：关闭滚动插值，直接显示完成状态；移动端缩短滚动距离并降低缩放范围。

## 6. 正式首页

首页保持四个主要层次：

1. 72px 顶部导航。
2. 左文右图的现代法式厨房主视觉。
3. 三项精选空间系列：厨房定制、餐边收纳、衣帽空间。
4. 深胡桃色的四步流程：提交需求、上门测量、方案确认、生产安装。

主视觉与精选系列之间增加单一悬浮式方案入口：左侧为“从一张户型图开始”的说明，右侧提供“上传户型”和“描述需求”操作。它跨接两个背景层并承担主要功能入口，不扩展成服务列表或指标栏。

## 7. 页面模板

### 7.1 列表页

产品与案例列表使用开放式网格，图片为视觉主体，标题与材质/风格说明位于图片下方。筛选区使用一行紧凑控件，移动端允许折叠。订单列表优先使用紧凑表格，不改造成卡片墙。

### 7.2 详情页

详情页使用主图/画廊与信息栏的双栏结构。字段名称和业务含义保持稳定；移动端改为单列，重要操作保持可见。

### 7.3 表单页

在线定制采用分组但不过度卡片化的长表单。厨房/空间信息、尺寸、风格材质、预算交期、补充描述按标题与分隔线组织。标签宽度、输入宽度、错误提示和底部操作统一。

### 7.4 工作台与订单

工作台采用宽主栏和窄服务栏：当前订单使用一块主要边框容器，状态进度清晰展示；历史订单用表格；服务顾问、最新方案和 AI 助手位于右栏。状态用“小圆点 + 文字”表示，避免全页面药丸标签。

订单详情展示订单基本信息、配置摘要、设计方案、生产工序时间轴和交付信息。只展示静态请求层实际提供的字段。

### 7.5 对话与状态页面

AI 助手保留真实的本地交互状态：用户发送文字后由静态服务返回预置建议，不调用真实大模型。加载、空状态、错误状态和 404 使用统一文字层级、线性图标和操作位置，不创建虚假功能。

## 8. 组件与样式架构

- `layouts/PublicLayout.vue`：公共顶部导航、主内容和页脚。
- `components/common/AppHeader.vue`：桌面与移动导航。
- `components/common/AppFooter.vue`：统一页脚。
- `components/common/PageHeader.vue`：面包屑、标题、说明和页面操作。
- `components/common/StatusView.vue`：加载、空、错误状态。
- `components/common/OrderProgress.vue`：订单阶段展示。
- `components/common/MaterialSwatch.vue`：材质色板。
- `styles/tokens.css`：颜色、字体、间距、圆角、尺寸、层级变量。
- `styles/base.css`：重置、排版和通用页面容器。
- `styles/element.css`：Element Plus 变量和组件覆盖。
- `styles/components.css`：项目共享布局模式。
- `styles/responsive.css`：断点和响应式规则。

样式使用 CSS 自定义属性集中管理。页面优先组合共享类和组件，不复制大段局部样式。

## 9. 数据请求层

新增 `src/request/request.js`，对页面暴露统一的 `get`、`post`、`put`、`delete` 方法，并返回 Promise。静态阶段根据方法和 URL 从 `src/data/` 中读取数据，模拟轻微延迟以及标准响应结构：

```js
{
  code: 200,
  message: 'success',
  data: {}
}
```

各领域 API 文件位于 `src/api/`，页面只能调用领域 API，不直接导入静态数据。未来将 `request.js` 内部替换为真实 HTTP 客户端即可保持 API 函数签名和页面响应处理不变。

静态数据只用于展示已有业务流程，不创建经营统计、销售成绩或不属于客户端的后台数据。

## 10. 响应式策略

- `>= 1200px`：1200px 内容区，完整双栏与表格。
- `768px–1199px`：弹性内容区，网格减少列数，右栏下移。
- `< 768px`：移动导航、单列页面、横向可滚动的必要表格、堆叠表单操作。
- `< 480px`：缩小页面边距、标题和按钮组合，保留至少 44px 的触控区域。

所有页面必须检查横向溢出、图片裁切、中文换行、表格操作和固定元素遮挡。

## 11. 源码交付说明

除本设计规格外，项目根目录生成《前端布局与CSS实现说明.md》，面向源码验收说明：

- 全局容器和页面纵向节奏。
- Flexbox 在导航、操作栏和表单对齐中的用途。
- CSS Grid 在主视觉、图集、详情页和工作台中的用途。
- Sticky 与滚动进度在动画展示页中的用途。
- Element Plus CSS 变量覆盖方式。
- 响应式断点和降级规则。
- `request.js` 静态模式及未来 Django API 替换位置。

## 12. 验收标准

- Vue 3、Vue Router 和 Element Plus 正常运行。
- `npm run build` 通过，开发服务器固定运行在 `5173`。
- 所有定义路由均可访问，导航和核心按钮跳转正确。
- 正式首页符合已确认的现代欧式概念，悬浮方案入口位于主视觉与精选系列之间。
- 默认展示页能进入正式首页，滚动动画和减少动态效果模式均可使用。
- 页面从静态请求层获取数据，不在模板中直接硬编码业务列表。
- 表单校验、分页、筛选、对话框和静态聊天交互可操作。
- 桌面、平板和移动端无明显溢出、遮挡或不可读内容。
- 最终通过浏览器截图与已确认概念逐项对照，完成视觉一致性记录。
