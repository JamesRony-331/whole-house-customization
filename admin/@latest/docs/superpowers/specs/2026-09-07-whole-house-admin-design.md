# 木序定制管理端设计规格

## 1. 项目目标

在 `全屋定制项目/admin/@latest` 新建独立的 JavaScript + Vue 3 管理端项目，使用 Vue Router 和 Element Plus，开发端口固定为 `5172`。当前业务数据通过静态 `request.js` 返回，未来可替换为 Django API。

管理端与客户端保持同一“现代欧式住宅编辑部”品牌语言，但采用更紧凑的信息密度、深胡桃木侧栏、白色顶栏和暖灰工作区。

## 2. 明确排除范围

- 不建设“运营总览”页面或侧栏入口。
- 不建设“数据分析”页面、经营指标、图表或统计入口。
- 不虚构销售额、增长率、转化率等经营数据。
- 不更改现有客户端项目。

管理端登录成功后默认跳转至 `/requirements` 定制需求页面。

## 3. 路由与页面

- `/login`：管理端登录。
- `/requirements`：定制需求列表与受理。
- `/requirements/:id`：定制需求详情。
- `/customers`：客户管理。
- `/designers`：设计师管理。
- `/users`：系统用户管理。
- `/roles`：角色权限管理。
- `/products`：产品管理。
- `/cases`：案例管理。
- `/orders`：订单管理。
- `/orders/:id`：订单详情。
- `/schemes`：设计方案审核。
- `/production`：生产任务与工序进度。
- `/service`：智能客服记录。
- `/settings`：系统设置。
- `/:pathMatch(.*)*`：404。

列表页面支持静态筛选、分页、查看、新增或编辑对话框；所有修改仅更新当前前端内存状态，不声称已写入后端。

## 4. 导航与整体布局

管理端采用固定深胡桃木侧栏和顶部白色工具栏：

- 侧栏宽度 216px，可折叠至 64px。
- 品牌区显示“木序定制”和“管理端”。
- 导航分组为业务管理、生产供应、系统管理。
- 顶栏高度 64px，包含折叠按钮、面包屑、全局搜索、通知和管理员菜单。
- 主工作区背景为 `#F4F1EC`，页面内边距 24px。
- 页面标题、筛选条、表格和分页沿同一内容边线对齐。

## 5. 视觉设计系统

### 5.1 色彩

- 工作区背景：`#F4F1EC`
- 功能表面：`#FFFFFF`
- 深胡桃侧栏：`#2C211B`
- 侧栏悬停：`#3A2B23`
- 主文字：`#28231F`
- 次文字：`#746C64`
- 主强调：`#7B4C32`
- 古铜细节：`#A57A4A`
- 边框：`#DDD5C9`
- 成功：`#55705A`
- 警告：低饱和赭色
- 错误：低饱和暗红

禁止蓝紫渐变、玻璃拟态、重阴影、大圆角和装饰性彩色卡片。

### 5.2 排版与尺寸

- 品牌和页面标题可使用宋体气质字体。
- 导航、表格、表单和按钮使用中文无衬线字体。
- 基础字号 14px，表格辅助信息 12–13px。
- 页面标题 24–28px。
- 控件高度 34–36px。
- 表格行高 44–48px。
- 圆角 2–6px。
- 间距使用 8、12、16、20、24、32px。

### 5.3 层次

通过深色侧栏、白色顶栏、暖灰工作区、白色表格区域和细分隔线建立层次。一个页面默认只有一个主要工作表面；筛选与表格可以连续呈现，不把每组字段包成独立卡片。

## 6. 页面模式

### 6.1 列表管理页

页面由标题操作区、紧凑筛选区、批量操作、数据表格与分页组成。主要操作位于右上角，行内操作使用文字按钮。状态优先采用“小圆点 + 文字”，只在需要强调交互状态时使用小尺寸标签。

### 6.2 详情页

订单和需求详情使用内容主栏与窄侧栏：主栏展示基本信息、配置、关联方案和流程记录；侧栏展示负责人、截止时间和状态操作。重要状态更新通过统一宽度的对话框完成。

### 6.3 表单、对话框与抽屉

- 简短新增/编辑使用 560–680px 对话框。
- 复杂详情或审核使用 720px 抽屉。
- 标签宽度、字段间距、必填提示和底部按钮顺序保持一致。
- 取消在左、确认在右；危险操作不与主操作并列突出。

## 7. 业务页面要求

### 7.1 定制需求

展示需求编号、客户、空间、风格、预算、提交时间、负责人和状态。支持筛选、查看详情、分派设计师、标记已受理。详情保留客户描述、尺寸、材料偏好和户型文件名称。

### 7.2 客户与设计师

客户展示联系信息、所在城市、需求数量和最近联系时间。设计师展示专业方向、在办任务数量和状态。不得添加无业务依据的评分或业绩指标。

### 7.3 用户与角色权限

用户管理展示账号、姓名、角色、状态和最近登录时间。角色权限使用树形勾选结构，包含菜单访问与常用业务操作权限。静态阶段保存操作仅反馈本地成功。

### 7.4 产品与案例

产品管理展示名称、分类、风格、材质和发布状态；案例管理展示项目名称、空间、风格、面积和发布状态。新增编辑表单保持字段含义与客户端一致。

### 7.5 订单与方案审核

订单展示交付时间和当前阶段，详情展示客户、配置、预算、方案和生产时间线。方案审核展示版本、设计师、提交时间与审核状态，并提供通过或退回意见对话框。

### 7.6 生产任务

按订单展示责任人、计划时间、当前工序、进度和质检状态。详情使用工序时间线，不使用虚构实时设备数据。

### 7.7 库存、物料与供应商

物料展示名称、型号、分类、当前库存、安全库存、单位、供应商和预警状态。低于安全库存时显示预警。供应商展示名称、联系人、电话、供应物料和状态。

### 7.8 智能客服

展示静态客服会话记录、客户问题分类、时间和处理状态；详情抽屉展示对话内容并允许标记已处理。不得声称真实连接大模型或在线客服系统。

### 7.9 系统设置

包含平台基本信息、订单状态字典、库存预警规则和通知偏好。静态阶段保存至前端内存并显示明确反馈。

## 8. 组件与样式架构

- `layouts/AdminLayout.vue`：侧栏、顶栏和路由内容。
- `components/layout/AdminSidebar.vue`、`AdminHeader.vue`。
- `components/common/PageHeader.vue`、`FilterBar.vue`、`DataTable.vue`、`StatusText.vue`、`StatusView.vue`、`AppDialog.vue`、`DetailDrawer.vue`。
- `styles/tokens.css`、`base.css`、`element.css`、`components.css`、`responsive.css`。

共享列表页面通过配置化字段与通用表格保持一致，但复杂需求、订单、权限和生产页面使用独立组件，避免过度抽象。

## 9. 静态请求层

`src/request/request.js` 提供 `get`、`post`、`put`、`delete`，统一返回：

```js
{ code: 200, message: 'success', data: {} }
```

领域 API 位于 `src/api/`，静态数据位于 `src/data/`。页面只调用领域 API。筛选、分页、详情查询与状态修改均由静态处理器模拟，状态修改仅存在于页面生命周期或内存中。

## 10. 响应式策略

- `>= 1200px`：固定侧栏与完整表格。
- `768–1199px`：侧栏默认折叠，内容区保持紧凑。
- `< 768px`：侧栏改为抽屉，筛选区折叠，表格保留横向滚动。

管理端主要面向桌面，但不得在平板和手机出现导航不可达、固定层遮挡或页面横向溢出。

## 11. 验收标准

- 管理端位于 `admin/@latest`，使用 JavaScript、Vue 3、Vue Router 和 Element Plus。
- 端口固定为 `5172`，不影响客户端 `5173`。
- 不存在库存物料、供应商管理、运营总览和数据分析路由或导航。
- 登录后进入 `/requirements`。
- 所有定义页面可访问，列表筛选、分页、对话框、抽屉和本地状态操作可用。
- 页面数据经过静态 `request.js` 和领域 API。
- `npm test` 与 `npm run build` 通过。
- 使用浏览器检查登录、定制需求、订单、生产和库存关键页面。
- 桌面和移动端无明显溢出、遮挡或不可达操作。
